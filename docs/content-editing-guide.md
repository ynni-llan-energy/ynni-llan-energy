# Editing the website — a guide for content editors

This guide explains how to add and update content on the Ynni Cymunedol Llanfairfechan website using **Sanity Studio**, the content editing tool behind the site. No coding knowledge is needed.

If you get stuck at any point, don't worry — nothing you do here can break the website. Changes only go live once you click **Publish**, so you're always free to experiment.

## 1. Getting started

1. Go to **`https://ynnicymunedolllanfairfechan.cymru/studio`** in your web browser (Chrome, Safari, Edge or Firefox all work fine).
2. Log in with the email address you've been given access with. You may receive a one-time link or code by email — click it to sign in.
3. You'll land on the **Content** screen. This is Sanity Studio, sometimes just called "the Studio."

> 💡 Bookmark the `/studio` link so you can get back here quickly next time.

---

## 2. Finding your way around

On the left-hand side you'll see a menu with these sections (each one is shown in Welsh / English):

| Menu item | What it's for |
|---|---|
| **Gosodiadau'r Wefan / Site Settings** | Text shown on the homepage, About page and Contact page |
| **Newyddion / News** | News posts / updates |
| **Prosiectau / Projects** | The renewable energy projects you're running |
| **Tudalennau / Pages** | Membership, Accessibility and Privacy pages |
| **Pobl / People** | People (e.g. news authors, committee members) |

Click any item to see a list of existing entries, or to open that section's editor.

To find something quickly, click the **search icon** (magnifying glass) at the top of the screen and start typing — this searches everything, including content types that aren't in the left-hand menu, such as **Volunteer Roles**.

---

## 3. Saving vs. Publishing — the most important thing to know

- Sanity **saves your work automatically** as you type — you never need to click a "Save" button, and you won't lose your work if you close the tab.
- However, your changes are only a **draft** until you click the **Publish** button (top-right of the screen). Only published changes appear on the live website.
- If a document has unpublished changes, you'll see a small dot or "Edited" label — that's your reminder that Publish hasn't been clicked yet.
- You can leave a document as a draft for as long as you like before publishing — for example, while you're still writing a news post.

**Rule of thumb: write and check your content first, then click Publish when you're happy for it to go live.**

## 4. Adding a News post

1. In the left-hand menu, click **Newyddion / News**.
2. Click the **+ (Create new)** button.
3. Fill in the fields:
   - **Teitl (Cymraeg) / Title (English)** — the headline, in both languages. Both are required.
   - **Slug** — the web address for this post. It's generated automatically from the Welsh title, so you can usually leave it alone. Click "Generate" if it's empty.
   - **Dyddiad cyhoeddi / Published** — the date the post should be dated.
   - **Cynnwys (Cymraeg) / Content (English)** — the main body text, in both languages. Use the toolbar above the text box to add bold, headings, links and bullet points.
   - **Delwedd / Image** — an optional cover image (see [Working with images](#10-working-with-images) below).
   - **Awdur / Author** — pick who the post is by, from the People list.
   - **Crynodeb (Cymraeg) / Excerpt (English)** — a short 1–2 sentence summary shown on news cards (200 characters max).
4. Click **Publish** in the top-right when you're ready for it to go live.

## 5. Adding or updating a Project

1. In the left-hand menu, click **Prosiectau / Projects**.
2. Click **+ (Create new)** for a new project, or click an existing one to edit it.
3. Fill in:
   - **Enw'r prosiect (Cymraeg) / Project name (English)**
   - **Slug** — auto-generated from the Welsh name.
   - **Statws / Status** — choose one: *Proposed*, *In development*, *Active* or *Completed*. This controls what badge is shown on the website.
   - **Crynodeb (Cymraeg) / Summary (English)** — a short summary (max 400 characters).
   - **Disgrifiad llawn (Cymraeg) / Full description (English)** — the full project write-up.
   - **Delwedd / Image** — a photo representing the project.
   - **Capasiti (kW)** — installed generation capacity in kilowatts, if known (used in the site's stats).
   - **Lleoliad / Location** and **Dyddiad cychwyn / Start date** — optional extra details.
4. Click **Publish** when ready.

## 6. Adding or updating a Volunteer Role

Volunteer roles don't currently have their own entry in the left-hand menu — use the **search icon** at the top of the screen, type "volunteer" or "gwirfoddol", or use the **+ (Create new)** button at the top and choose **Rolau Gwirfoddol / Volunteer Roles** from the list of types.

Fields to fill in:
- **Teitl y rôl (Cymraeg) / Role title (English)**
- **Slug** — auto-generated from the Welsh title.
- **Statws / Status** — *Active*, *Filled* or *Closed*. Set this to *Filled* or *Closed* once you no longer need volunteers, rather than deleting the role.
- **Crynodeb (Cymraeg) / Summary (English)** — short summary shown on the roles list (max 300 characters).
- **Disgrifiad llawn (Cymraeg) / Full description (English)** — full details of the role (Welsh is required).
- **Ymrwymiad amser (Cymraeg) / Time commitment (English)** — e.g. "2–4 hours per week".
- **Sgiliau defnyddiol / Useful skills** — type a skill and press Enter to add it as a tag; add as many as useful.
- **Delwedd / Image** — an optional photo.

Then click **Publish**.

## 7. Updating People

Used for things like the author shown on a news post, or committee/team photos.

1. Click **Pobl / People** in the left-hand menu.
2. Click **+ (Create new)**, or select an existing person to edit.
3. Fill in **Enw / Name**, **Rôl (Cymraeg) / Role (English)**, and optionally a **Llun / Photo**.
4. Click **Publish**.

---

## 8. Editing the fixed Pages

The **Tudalennau / Pages** section contains three fixed pages that always exist — you can edit them, but you can't create new ones or delete them:

- **Aelodaeth / Membership**
- **Hygyrchedd / Accessibility**
- **Preifatrwydd / Privacy**

Click **Tudalennau / Pages**, choose the page you want to change, edit the **Pennawd (Cymraeg) / Heading (English)** and **Cynnwys (Cymraeg) / Content (English)** fields, then click **Publish**.

## 9. Editing Site Settings

**Gosodiadau'r Wefan / Site Settings** is a single set of settings (not a list) that controls text shown across the site:

- **Hero section** — the big heading and intro text on the homepage.
- **About summary** — the "about us" paragraph.
- **Egwyddorion / Principles** — the grid of principles on the About page. Use the **+** button within this field to add a new one, or the handle/drag icon to reorder them, in both Welsh and English.
- **Contact section** — the intro text and contact email shown on the Contact page.
- **Dolenni cymdeithasol / Social links** — add a platform name (e.g. "Facebook") and its URL; add more rows with **+**.

Click **Publish** after making changes — this is a single shared document, so anyone else editing it will see your changes once published.

## 10. Working with images

- Click the image field and either drag a photo in or click to browse your computer.
- Once uploaded, you can click and drag to set the **hotspot** — the part of the image that stays visible when it's cropped for different parts of the site.
- **Always fill in the Alt text field.** This is a short written description of the image (e.g. "Solar panels on the community hall roof") that's read aloud by screen readers for visually impaired visitors, and is required for accessibility. Some image fields will show a warning until this is filled in.
- Use clear, well-lit photos where possible — large image files will be resized automatically by the website.

---

## 11. Writing in Welsh and English

This website is bilingual, so almost every piece of content has a Welsh version and an English version, usually shown as two separate fields (Welsh field first, then English). A few tips:

- The **Welsh field is usually required** — English is often optional, but it's best practice to fill in both wherever you can.
- Web addresses (**slugs**) are generated from the **Welsh** title.
- You don't need to translate word-for-word — write naturally in each language.

## 12. Common questions

**I can't see the Publish button / it's greyed out.**
This usually means there are no unsaved changes to publish, or a required field (shown with a red marker) hasn't been filled in yet. Scroll up to check for any fields marked as required.

**I made a mistake after publishing — can I undo it?**
Yes. Edit the document again with the correct content and click Publish again. Sanity also keeps a history of previous versions — click the clock/history icon at the top of a document if you need to look back at an earlier version.

**Can I delete something by mistake?**
You'd need to deliberately open the menu (⋮) on a document and choose Delete, then confirm — it won't happen by accident from normal editing.

**Where do Volunteer Roles show up if they're not in the menu?**
Use the search icon at the top of the Studio, or the **+ (Create new)** button and pick the type from the list — see [section 6](#6-adding-or-updating-a-volunteer-role).

**Who do I contact if I'm stuck?**
Contact whoever manages the website for Ynni Cymunedol Llanfairfechan — they can also grant Studio access to new editors.
